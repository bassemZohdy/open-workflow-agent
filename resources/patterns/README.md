# Portable agent patterns

[assistant.yaml](assistant.yaml) and [pipeline.yaml](pipeline.yaml) use ordinary OWS calls to the canonical agent catalog. Provider/model/credentials remain runtime configuration. These recipes do not claim old SDK/API or role-specific behavior compatibility.

[pattern-catalog.json](pattern-catalog.json) preserves all eight requested pattern families and identifies remaining work. The definitions are independently written; no unlicensed generic-agent-lang code is included. Approval must use the existing protected service, with pending, unknown, rejected or expired requests refusing side effects.

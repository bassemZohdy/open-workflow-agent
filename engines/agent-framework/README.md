# open-workflow-agent-agent-framework

Microsoft Agent Framework adapter for the Open Workflow Agent. Wraps the shared immutable workflow plan through the Agent Framework engine SPI and native tool boundary. This adapter is optional and is not yet a production image/release target; task-level plan-to-framework compilation is not yet claimed.

See the [repository root](https://github.com/BassemZohdy/open-workflow-agent) for documentation.

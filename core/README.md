# open-workflow-agent-core

Framework-neutral contracts and services for the Open Workflow Agent: configuration, Open Workflow 1.0.3 loading/validation, normalization, the immutable internal execution plan, jq semantics, catalog resolution, knowledge/memory/session/approval/schedule state, bounded protocol clients, sandbox execution contracts, and the common error contract.

This package is consumed by the engine adapters (`open-workflow-agent-adk`, `open-workflow-agent-langgraph`, `open-workflow-agent-agent-framework`). See the [repository root](https://github.com/BassemZohdy/open-workflow-agent) for documentation.
